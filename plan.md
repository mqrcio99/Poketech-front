# Plano — frontend moderno do Poketech

## Direção visual

Escolha: dashboard editorial / tech-lab. A interface usa fundo profundo, verde-lima como assinatura, azul elétrico como apoio, cards com profundidade e tipografia sans-serif com mono para números. A navegação será arejada e responsiva, com foco no jogo e na descoberta dos Pokémon.

## Entregas

- Catálogo local dos 151 Pokémon para desenvolvimento offline.
- Busca por nome ou número.
- Cards e detalhes modernos.
- Tela inicial do jogo com tentativas dinâmicas locais.
- Tema claro/escuro.
- Rotas internas para home, Pokédex, detalhes e 404.
- Camada de serviço preparada para substituir mock por backend.
